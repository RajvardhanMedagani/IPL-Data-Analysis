# IPL Performance Analytics Mini Project

This project contains a Python notebook, cleaned CSV, report and Power BI preparation files.

### Files
- IPL_Cleaned.csv
- IPL_Data_Analysis.ipynb
- IPL_Project_Report.pdf
- PowerBI_DAX_Measures.txt
- PowerBI_Import_Instructions.txt
- PowerBI_Dashboard_Preview.png

### Dataset note
The included CSV is a practice dataset generated to match the institute's requested schema. If your institute supplied an official IPL CSV, replace the CSV and rerun the notebook before final submission.
